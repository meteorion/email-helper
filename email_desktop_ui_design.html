1. 设计风格与设计理念

设计原则

  • 信息密度适中：邮件列表紧凑但不拥挤，兼顾效率与可读性
  • 视觉层次清晰：通过颜色、字号、间距区分信息优先级
  • 操作可达性高：核心操作（写邮件、回复、搜索）触手可及
  • 一致性强：全局统一的圆角、配色、间距、交互反馈

布局模式

  • 四栏式布局：Rail导航 + 文件夹 + 邮件列表 + 详情
  • 响应式宽度：各列可拖拽调整宽度（Flet: Row + 多个 Container(width=...)，拖拽分隔需自定义 GestureDetector，Flet 0.27 无内置 split_col 组件）
  • 沉浸式阅读：邮件详情区域占比最大
  • 固定导航：Rail始终可见，快速切换模块

交互设计

  • 即时反馈：hover/active/pressed 三态视觉变化
  • 键盘优先：支持 J/K 导航，N 新邮件，R 回复
  • 拖拽操作：邮件拖入文件夹，附件拖入上传
  • 快捷操作浮层：列表项hover浮现快捷按钮

Flet 布局实现方式

核心代码结构

import flet as ft

def main(page: ft.Page):
    # 主题配置 (Flet 0.27 中 Material 3 为默认且唯一选项，无需 use_material3 参数)
    page.theme_mode = ft.ThemeMode.LIGHT
    page.theme = ft.Theme(color_scheme_seed="blue")
    page.padding = 0
    page.spacing = 0

    # 四栏主布局 (Row 包裹，可拖拽)
    main_layout = ft.Row(
        spacing=0,
        expand=True,
        controls=[
            # Col1: NavigationRail (固定 72px)
            ft.Container(width=72, bgcolor="#1e3a8a", content=ft.NavigationRail(...)),
            # Col2: 文件夹 (260px，可调整)
            ft.Container(width=260, bgcolor="#f8fafc", content=folder_list_view),
            # Col3: 邮件列表 (380px，可调整)
            ft.Container(width=380, content=email_list_view),
            # Col4: 邮件详情 (自适应)
            ft.Container(expand=True, content=email_detail_view),
        ]
    )
    page.add(main_layout)

CSS → Flet 迁移难点提示

以下 CSS 特性在 Flet 中无直接等价物，需通过事件回调或自定义绘制实现：

  • :hover 伪类 → 需用 on_hover 事件回调动态修改 bgcolor
  • ::before / ::after 伪元素 → 需用嵌套 Container + Stack 模拟
  • content: attr(data-x) → 需在 Python 中拼接字符串
  • 多停 linear-gradient → Flet 仅支持 LinearGradient 简单形式，复杂渐变需拆分多层 Container
  • 多重 box-shadow → Flet Container.shadow 仅支持单阴影列表，复杂投影需叠加
  • :focus-visible 焦点环 → 需在 on_focus/on_blur 中切换 border
  • 响应式 @media → 需监听 page.on_resized 动态调整列宽

7. 核心交互流程 & 快捷键

邮件交互流程

  1. 进入应用 → 默认聚焦「收件箱」
  2. 未读邮件左侧显示蓝色竖条 + 粗体
  3. 点击邮件 → 右侧详情区加载内容
  4. 邮件标记为已读（蓝色竖条消失）
  5. 滚动阅读 / 点击附件下载 / 点击回复

撰写邮件流程

  1. 点击「撰写」按钮 → 弹出撰写窗口
  2. 支持：收件人联想 + 标签
  3. 富文本编辑：加粗/斜体/列表/链接
  4. 拖拽或点击上传附件
  5. 发送 → Toast 「发送成功」提示

全局快捷键

  • N   撰写新邮件
  • R   回复当前邮件
  • F   转发邮件
  • J / K   上/下 一封
  • #   删除邮件
  • S   星标切换
  • Ctrl+F   搜索
  • Ctrl+Enter   发送邮件
